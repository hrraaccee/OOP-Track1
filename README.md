# Объектно ориентированное программирование Трек 1

Решения заданий курса ТИУ: спринты 0–5, Task0–Task3, и четыре задания спринт ревью 0–3. Индивидуальный проект — вариант 1, модель людей Person, Student, Employee, Teacher. Треки 2 и 3 в этот репозиторий не входят.

## Структура

В каждой папке SprintN лежат четыре ноутбука Task0.ipynb–Task3.ipynb. Рядом размещены одноимённые каталоги с Program.cs и отдельным .csproj. Код в ноутбуке совпадает с соответствующим Program.cs. Reviews содержит отдельные консольные проекты по присланным заданиям ревью.

## Запуск ноутбуков

Откройте .ipynb в Visual Studio Code с расширением Microsoft Polyglot Notebooks и выберите ядро C#. Каждый ноутбук самодостаточен: выполните его единственную ячейку кода целиком. Перед повторным выполнением или переходом между решениями с одинаковыми именами классов перезапустите ядро. Ввод через Console.ReadLine не требуется.

## Запуск консольных проектов

Установите .NET SDK 8 или новее с пакетом целевой платформы .NET 8. Внешние NuGet-пакеты не используются. Решение Track1.sln открывается в Visual Studio 2022, поддерживающей .NET 8.

```powershell
dotnet run --project Sprint0/Task0/Sprint0.Task0.csproj
dotnet run --project Sprint5/Task3/Sprint5.Task3.csproj
dotnet run --project Reviews/Review3/Reviews.Review3.csproj
```

Все демонстрации завершаются встроенными проверками результата и пограничных случаев. Исключение означает неудачную проверку. Успешный запуск печатает «Проверки выполнены успешно».

```powershell
./verify.ps1
```

## Уточнения заданий

Ревью — самостоятельные работы, поэтому их классы не смешиваются с вариантом индивидуального проекта. Два присланных документа ревью 0 идентичны; выполнено одно решение. В ревью 2 Employee конкретный: условие требует создать его экземпляр. В ревью 3 ToString — переопределяемый метод, а не оператор. Для множественного наследования используются интерфейсы. В generic-коллекцию базового типа можно добавлять разные наследники; коллекция Dog принимает только Dog и его наследников.

Имена, цены и организации в примерах — демонстрационные данные. В C#-коде комментариев нет.
